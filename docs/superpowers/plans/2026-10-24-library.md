# Techniques Library Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Library row on the title menu opens a map of all 36 techniques by level. Picking one shows the tutor's `t`,`t` lesson screen for it, and `↑ ↓` reads them in order.

**Architecture:** A small `src/library.rs` holds the library's state (`Library::Map` / `Library::Lesson`) and its pure navigation. `App` gains `library: Option<Library>`, a base screen shown in place of the title menu while there's no game. New `Action`s feed it, and `App::apply` stays the one place that decides. The tutor's explain screen is pulled out of `ui::draw_game` into `ui::draw_explain(header, example, stage, keys)` so the game and the library draw it with the same code. The map is drawn by a new `src/ui/library.rs`.

**Tech Stack:** Rust 2024, Ratatui (TestBackend for render tests), crossterm. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-24-library-design.md`

## Global Constraints

- Library is reachable **only from the title menu**. Don't add it to the in-game `d` popup, and don't add any way back to the title screen from a game.
- The lesson screen differs from the tutor's `t`,`t` screen only in the header's top line and the key list. Same example, steps, legend, drawing. Reuse the code; don't copy it.
- Opening the library never touches the saved game, best times or the 🎓 counter.
- Gists use general terms (no cell names, no digits), each lesson's own words, at most 60 characters.
- Every screen fits the minimum terminal, `MIN_W x MIN_H` = 103x39.
- Keys and clicks both become `Action`s, and `App::apply` decides what they do. The library is a base screen, not an `Overlay`, so Help (`?`) opens over it.
- `q` / Ctrl+C quit from every screen (already global in `key_action`; don't break it).
- Baseline: 194 tests pass. Every task ends with `cargo test`, `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` clean.
- Commit messages: imperative sentence, no `feat:` prefix (match `git log`), ending with the `Co-Authored-By` trailer the session gives.

## Review Focus

1. **Minimum terminal:** at 103x39 every name in all five columns, the gist line and the map's footer are whole, and the lesson screen fits as the tutor's does. Tested in Task 5.
2. **Help over the library:** `?` on the map or a lesson opens Help, and `Esc` returns to the same library screen, not the title. Tested in Task 4.
3. **A saved game:** visiting the library and coming back leaves `resume` alone. Continue is still the first row and `c` still continues. Tested in Task 4.
4. **Stray clicks on the map:** clicking an empty slot under a short column, the popup border, or outside the popup does nothing. It never opens the wrong technique. Tested in Task 5.
5. **Turning pages resets the stage:** `↑ ↓` on a lesson opens the next technique at stage 0, not at the stage you were on, and `Esc` lands the map on that technique. Tested in Task 4.
